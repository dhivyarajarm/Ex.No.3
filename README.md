# EX. NO. 3 – SCENARIO-BASED REPORT DEVELOPMENT USING DIVERSE PROMPTING TECHNIQUES

Register Number:212225040076

## AIM

To develop and evaluate different types of prompts using an **AI-Based Smart Hospital Patient Support System** and study how different prompting techniques influence the format, clarity, and usefulness of AI-generated responses.

---

## USE CASE: AI-BASED SMART HOSPITAL PATIENT SUPPORT SYSTEM

### Scenario

A modern hospital wants to introduce an AI-based patient support system to make routine hospital services easier for patients. The system can help patients identify available departments, check doctor availability, request appointments, receive reminders for scheduled visits, obtain general health information, and maintain simple daily wellness records.

The system is designed to provide quick assistance for routine queries while reducing the workload involved in handling repetitive patient requests. It supports patients throughout their hospital visit by providing timely information and reminders.

The AI system is intended to **improve accessibility, reduce unnecessary waiting, organize patient activities, and enhance the overall hospital experience.**

---

# 1. STRAIGHTFORWARD PROMPTING

### Prompt

**“Describe how an AI-based hospital support system can help a patient before, during, and after a hospital visit.”**

### Generated Response

An AI-based hospital support system can assist patients at different stages of their hospital journey. Before a visit, it can provide information about doctors, departments, available appointments, and scheduled timings. During the visit, it can guide patients towards the appropriate department and provide general information about hospital services. After the visit, it can send reminders for follow-up appointments and help patients remember their healthcare activities.

### Evaluation

- Gives a focused response to the given instruction.
- Covers different stages of patient interaction.
- Produces information in a simple and understandable form.
- Avoids unnecessary technical details.
- Useful when a **quick overview of a system is required**.

---

# 2. TABULAR FORMAT PROMPTING

### Prompt

**“Prepare a table showing the patient problems, AI-based solutions, and expected outcomes of a Smart Hospital Support System.”**

### Generated Response

| Patient Problem | AI-Based Solution | Expected Outcome |
|---|---|---|
| Difficulty finding the correct department | Provides department guidance | Easier navigation |
| Difficulty getting appointment information | Shows available appointment details | Faster appointment planning |
| Forgetting scheduled visits | Sends timely notifications | Fewer missed appointments |
| Repeatedly asking common questions | Provides instant general information | Saves staff time |
| Difficulty remembering follow-up dates | Creates follow-up reminders | Better continuity of care |
| Lack of awareness about daily wellness | Records basic wellness activities | Encourages healthy habits |

### Evaluation

- Converts information into a **three-column structure**.
- Clearly connects problems with solutions.
- Makes the expected outcomes easy to identify.
- Suitable for project reports and presentations.
- Helps readers understand the practical value of the AI system.

---

# 3. PRECEDING QUESTION PROMPTING

### Prompt

**“What difficulties might a patient face while using hospital services? Think about appointment delays, finding departments, remembering follow-up dates, and obtaining routine information. Now explain how an AI-based hospital support system can address these difficulties.”**

### Generated Response

Patients may face several routine difficulties while using hospital services. They may not know which department to visit, have difficulty obtaining appointment information, or forget important follow-up dates. Repeated enquiries can also increase the workload of hospital staff.

An AI-based support system can reduce these difficulties by guiding patients to the appropriate departments, providing appointment-related information, answering routine questions, and sending reminders for future visits. As a result, patients can access services more conveniently while hospital staff can focus more on essential responsibilities.

### Evaluation

- First identifies the **problem situation**.
- Uses the identified problems to develop suitable solutions.
- Produces a connected and logical explanation.
- Encourages the AI to consider the scenario before answering.
- Appropriate for **problem analysis and solution-oriented tasks**.

---

# 4. MISSING WORD PROMPTING

### Prompt

**Complete the following statements using suitable terms related to the Smart Hospital Support System.**

1. The AI system can help patients find the appropriate hospital __________.
2. Patients can receive notifications about their __________ appointments.
3. The system can provide general __________ information.
4. AI can reduce the workload caused by repeated patient __________.
5. Daily activities can be recorded for basic __________ monitoring.

### Generated Response

1. **department**
2. **follow-up**
3. **health**
4. **enquiries**
5. **wellness**

### Evaluation

- Checks whether the AI understands the context.
- Uses meaningful terms related to hospital services.
- Provides a simple method for testing comprehension.
- Can be used for classroom activities and assessments.
- Helps reinforce important concepts from the scenario.

# COMPARATIVE ANALYSIS OF PROMPTING TECHNIQUES

| Technique | Response Style | Main Advantage | Application |
|---|---|---|---|
| **Straightforward Prompting** | Direct explanation | Fast and focused output | System overview |
| **Tabular Prompting** | Structured information | Easy comparison | Project documentation |
| **Preceding Question Prompting** | Problem followed by solution | Better contextual response | Analysis |
| **Missing Word Prompting** | Short contextual answers | Tests understanding | Learning activities |

---

# OBSERVATION

The experiment shows that the **same AI system can produce different types of responses depending on the prompt structure**.

- Direct prompts are useful when only a brief explanation is required.
- Tables are effective when several points need to be compared.
- Preceding questions help the AI understand the problem context before generating a solution.
- Missing-word prompts are useful for checking whether important concepts are understood.

Hence, prompt design plays an important role in determining the **format and usefulness of AI-generated content**.

---

# CONCLUSION

The experiment successfully demonstrated the application of four prompting techniques in the development of an **AI-Based Smart Hospital Patient Support System**. Each technique served a different purpose and produced a different style of response.

Straightforward Prompting was useful for generating direct explanations, while Tabular Prompting presented information in an organized manner. Preceding Question Prompting supported problem-based reasoning, and Missing Word Prompting was effective for testing contextual understanding.

Therefore, **choosing the right prompting technique according to the required task can improve the quality, clarity, and usability of AI-generated responses.**
